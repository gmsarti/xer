# Como Acessar front.html de Referência

Para adaptar o design visual do Xer baseado no `front.html`, preciso ter acesso ao arquivo de referência.

## Opções para Compartilhar

### Opção 1: Copiar para o Projeto Atual (Recomendado)
```bash
cp /Users/gustavosarti/Work/code/xerazadi/front.html \
   /Users/gustavosarti/Work/code/xer/docs/reference_front.html
```

### Opção 2: Dar Permissão para Acessar Diretório
Permitir acesso ao workspace `/Users/gustavosarti/Work/code/xerazadi/`

### Opção 3: Compartilhar Conteúdo Manualmente
Copiar e colar o conteúdo do HTML aqui no chat

## Próximos Passos Após Acesso

1. Analisar elementos visuais do front.html:
   - Paleta de cores
   - Tipografia
   - Layout e espaçamento
   - Componentes e padrões
   
2. Adaptar `static/css/main.css` com novo design system

3. Atualizar templates (`base.html`, `index.html`) com nova estrutura

4. Testar visualmente as mudanças
